std::function< void()> onDirty = nullptr )

Handles canvas mouse clicks on the audio badge (play button, scrubber).

Mathematical Hit Testing: Badge origin: (worldX, worldY), dimensions (chipW, chipH). Play/Pause button: circular zone at left [worldX + 2.0, worldY + 2.0] to [worldX + 18.0, worldY + 20.0]. Scrubber bar: horizontal zone [worldX + 20.0, worldY + 14.0] to [worldX + chipW - 4.0, worldY + 19.0].

Parameters
wxWorld X coordinate of mouse click in millimeters.
wyWorld Y coordinate of mouse click in millimeters.
onDirtyCallback to signal canvas repaint.
Returns
True if click hit a control (play button or scrubber); false otherwise.
