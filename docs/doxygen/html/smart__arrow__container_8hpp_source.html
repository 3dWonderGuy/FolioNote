2/**
3 * @file smart_arrow_container.hpp
4 * @brief Two-point line and arrow connector object with draggable endpoint handles.
5 *
6 * SmartArrowObject represents a directed line segment on the canvas. Unlike
7 * closed shapes (ShapeObject), it:
8 * - Has exactly 2 control points: start (x1, y1) and end (x2, y2)
9 * - Exposes 2 custom gizmo handles (endpoint drag) instead of 8 bounding-box grips
10 * - Supports 4 arrowhead styles on each endpoint (None, Triangle, Stealth, Open, Circle)
11 * - Cannot have a fill (it is an open path by definition)
12 * - Uses the same outline styles as ShapeObject (Solid, Dashed, Dotted, DashDot)
13 *
14 * Routing Options:
15 * - Straight: Direct linear segment connecting start and end.
16 * - Curved: Cubic Bézier with automatic horizontal/vertical tangent control points.
17 * - Elbow: Orthogonal Manhattan 3-segment routing with midpoint step.
18 *
19 * Transform Contract:
20 * - ApplyTransform(): accumulates in BLMatrix2D without mutating x1/y1/x2/y2.
21 * - BakeTransform(): maps endpoints through the matrix, resets to identity.
22 * - Called by SelectionGizmo::OnPointerUp() same as ShapeObject.
23 *
24 * Gizmo Handles:
25 * - customId 0 = start endpoint (x1, y1)
26 * - customId 1 = end endpoint (x2, y2)
27 * - TwoPoint gizmo drag updates the dragged endpoint directly (no matrix needed
28 * for individual endpoint adjustment — it is always a world translation).
29 */

97 /**
98 * @brief Computes cubic Bézier control points for Curved connector routing.
99 *
100 * Mathematical derivation:
101 * Evaluates dominant orientation: dx = x2 - x1, dy = y2 - y1.
102 * - If |dx| >= |dy|: Horizontal tangents at mid-span:
103 * C1 = (x1 + 0.5 * dx, y1)
104 * C2 = (x2 - 0.5 * dx, y2)
105 * - If |dy| > |dx|: Vertical tangents at mid-span:
106 * C1 = (x1, y1 + 0.5 * dy)
107 * C2 = (x2, y2 - 0.5 * dy)
108 *
109 * @param[out] outC1 First Bézier control point
