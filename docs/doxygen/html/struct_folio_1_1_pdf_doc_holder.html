Detailed Description

RAII container managing FPDF_DOCUMENT lifecycles across platforms. Supports both standard native FPDF_LoadDocument descriptors and custom FPDF_FILEACCESS streams via SDL_IOStream to handle Unicode paths on Windows. Automatically releases PDFium document handles and underlying file streams upon destruction.
