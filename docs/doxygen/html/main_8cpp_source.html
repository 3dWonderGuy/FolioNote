1/**
2 * @file main.cpp
3 * @brief Application entry point and CLI orchestration for FolioNote.
4 *
5 * GENERAL WORKING PROCESS & ARCHITECTURE:
6 * ---------------------------------------
7 * 1. CLI Dispatch & Headless Utility Mode:
8 * FolioNote supports headless command-line execution for administrative system
9 * integrations (such as virtual printer installation and query) as well as document
10 * import dispatching.
11 * - Headless printer configuration: Invoked by installers or automated scripts via
12 * `--install-printer`, `--uninstall-printer`, or `--check-printer`. These exit
13 * immediately with process code 0 (success) or 1 (failure) without initializing
14 * the graphical subsystem.
15 * - Direct document import: When launched via Explorer context menu ("Import into FolioNote"),
16 * SendTo shortcut, or direct shell command (`--import <file.pdf>` or bare `.pdf` path),
17 * the path is captured and forwarded into the GUI application lifecycle.
18 *
19 * 2. GUI Engine Initialization:
20 * If no headless termination flags were requested, the program instantiates the core
21 * `Application` instance and executes `app.Init(title, width, height, initialImportPath)`.
22 * - Initializes SDL3 video, custom modern window framing, and OpenGL 3.3 / GLES 3.0 context.
23 * - Connects database storage, themes, input devices, and canvas subsystems.
24 * - If an initial import path was provided, copies/stages the document into the dedicated
25 * user imports directory (`Documents/FolioNote/Imports`) and immediately presents the
26 * interactive `PdfImportModal` prompting the user where to place it in the notebook.
27 *
28 * 3. Event Loop Execution:
29 * Delegates runtime execution to `app.Run()`, maintaining 120Hz/60Hz adaptive frame pacing
30 * and continuous input state machine evaluation until the application terminates.
31 */
