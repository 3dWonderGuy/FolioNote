12/**
13 * =========================================================================================
14 * @file db_manager.hpp
15 * @brief Thread-Safe SQLite Database Manager for FolioNote Notebooks (.fn Packages)
16 * =========================================================================================
17 *
18 * --- ARCHITECTURE OVERVIEW ---
19 * FolioNote notebooks are organized as structured package directories containing an embedded
20 * SQLite database for metadata, sections, and page catalogs, alongside isolated `.ink` binary
21 * files for high-speed page graphics payloads.
22 *
23 * Storage Hierarchy:
24 * ┌─────────────────────────────────────────────────────────────────┐
25 * │ Notebook Package Directory (.fn) │
26 * │ ├── notebook.db (SQLite database: schema, meta, sections) │
27 * │ ├── notebook.db-wal (High-throughput Write-Ahead Log) │
28 * │ └── pages/ │
29 * │ ├── [page_guid_1].ink (Compressed vector graphics) │
30 * │ ├── [page_guid_1].ink.wal (Instant action journal) │
31 * │ └── [page_guid_2].ink │
32 * └─────────────────────────────────────────────────────────────────┘
33 *
34 * Key Responsibilities of DBManager:
35 * - High-concurrency WAL mode configuration with zero UI thread blocking.
36 * - ACID transaction lifecycle management (Begin, Commit, Rollback).
37 * - Upsert and retrieval of Notebook metadata, hierarchical Sections, and Page metadata.
38 * - Memory-mapped I/O (MMAP) and indexed queries for sub-millisecond retrieval.
39 */
