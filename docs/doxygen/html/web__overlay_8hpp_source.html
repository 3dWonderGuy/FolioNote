1/**
2 * =========================================================================================
3 * @file core/overlay/web_overlay.hpp
4 * @brief Live Web View and YouTube Player Overlay Subsystem for FolioNote Layer 3
5 *
6 * Architecture Context:
7 * FolioNote Layer 3 interactive overlays host live, interactive components anchored to
8 * world-space coordinates on the infinite canvas.
9 *
10 * Capabilities:
11 * 1. Official YouTube Playback: Uses embedded iframe playback (https://www.youtube.com/embed/<id>)
12 * which provides full native YouTube controls (play/pause, scrubber, volume slider,
13 * captions, gear settings for quality, fullscreen) with zero scraping failure risk
14 * and full Terms of Service compliance.
15 * 2. Generic Web Page Embedding: Can embed any modern live URL (Wikipedia, Desmos graphing
16 * calculator, documentation, HTML5 apps, etc.).
17 * 3. Zero-Allocation Dual-Mode Virtualization:
18 * - Dormant Mode: Renders a lightweight Blend2D card with poster thumbnail, domain badge,
19 * and "Click to Play Live" callout. Consumes ~0 MB additional RAM.
20 * - Live Mode: Creates an OS child window hosting Edge Chromium (WebView2). Coordinates
21 * track the canvas viewport projection during pan/zoom in real time.
22 * 4. Integrated Canvas Interaction Header:
23 * A 36px top title bar permits moving/dragging the card across the canvas with selection
24 * gizmos, toggling live mode, reloading, and opening in external browser.
25 * =========================================================================================
26 */
