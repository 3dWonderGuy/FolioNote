2/**

4 * @file ui/overlays/command_palette.hpp
5 * @brief Spotlight-Style Interactive Action Search & Command Palette Modal
6 * =========================================================================================
7 *
8 * ARCHITECTURAL DESIGN & PURPOSE:
9 * --------------------------------
10 * The ActionCommandPalette is a modern, keyboard-first modal popup (triggered via Ctrl+K,
11 * Ctrl+P, or titlebar search) allowing users to discover, search, and execute any application
12 * capability registered in the `UIActionRegistry`.
13 *
14 * WORKING PROCESS:
15 * 1. Invocation:
16 * User presses `Ctrl+K` or clicks the Search icon. `Open()` is called, which initializes
17 * the search query buffer and sets focus to the search text input.
18 * 2. Instant Query & Filtering:
19 * As the user types, the palette performs case-insensitive substring matching against
20 * action labels, categories, and keywords.
21 * 3. Keyboard Navigation:
22 * - Up / Down arrow keys: navigate candidate list.
23 * - Enter key: dispatches the highlighted action immediately and closes the palette.
24 * - Escape key or click-outside: dismisses the palette without execution.
25 * 4. Visual Layout:
26 * - Centered glassmorphic floating modal.
27 * - Top search bar with magnifying glass icon.
28 * - Scrollable results list with icon, category badge, and keyboard shortcut hint.
29 */
