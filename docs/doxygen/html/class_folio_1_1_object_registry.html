bool Folio::ObjectRegistry::Register ( ObjectType type,

ObjectFactoryFn factory,

static

Registers a custom factory function and metadata descriptor for an ObjectType.

GENERAL WORKING PROCESS:

  1. Acquires unique lock over the internal registration table.
  2. Emplaces or overrides the ObjectTypeMetadata entry keyed by type.
  3. Emits an info diagnostic log confirming registration.
Parameters
[in]typeDiscriminated type tag.
[in]typeNameHuman-readable type string.
[in]factoryCallable returning a new std::shared_ptr<CanvasObject>.
[in]defaultIconOptional default UI icon glyph.
[in]isSerializableWhether this entity type participates in binary persistence.
Returns
true if registration succeeded; false if factory was null.
