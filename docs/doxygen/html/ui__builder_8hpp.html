Detailed Description

Fluent Widget Factory & Button Generation for FolioNote Modern UI.

autotoc_md466

GENERAL ARCHITECTURE:

UIBuilder replaces repetitive raw ImGui code with a fluent, declarative component builder. Every widget integrates with UIAnimationManager for smooth hover/press transitions and UIShapeManager for multi-pass shadows, acrylic surfaces, and rounded squircles.
