2/**
3 * =========================================================================================
4 * @file core/layers/embedded_app_layer.hpp
5 * @brief Layer 3 Host: Runtime Coordinator for Running Embedded Widgets and Native Controls
6 * =========================================================================================
7 *
8 * ARCHITECTURAL ROLE & COORDINATE PROJECTION:
9 * -------------------------------------------
10 * In FolioNote's 3-layer compositing system, `EmbeddedAppLayer` serves as Layer 3:
11 * 1. Runtime Isolation:
12 * - Manages live interactive applications embedded within canvas documents, such as
13 * video playback surfaces (libVLC), web browser views (WebView2), or live code editors.
14 * - Decouples app rendering execution from the static vector baking pipeline (Layer 1).
15 *
16 * 2. Coordinate Mapping:
17 * - Each mounted app is associated with a document `CanvasObject` defining spatial bounds
18 * in physical canvas world millimeters (worldX, worldY, worldWidth, worldHeight).
19 * - Layer 3 projects these coordinates through `viewport.worldToScreenMatrix` every frame
20 * to produce an integer or sub-pixel screen viewport `AppScreenRegion` in device pixels:
21 * p_screen = M_worldToScreen * p_world
22 *
23 * 3. Lifecycle & Memory Safety:
24 * - Apps are registered via `MountApp(uid, unique_ptr<IEmbeddedApp>)`.
25 * - Controlled teardown via `DismountApp(uid)` and `OnTeardown()` prevents resource leaks
26 * when objects are deleted from the active page.
27 */
