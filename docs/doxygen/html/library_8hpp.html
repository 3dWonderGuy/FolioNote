Detailed Description

Public API for the FolioNote Library Subsystem (Bundles, Discovery, Routing, Trash)

autotoc_md92

ARCHITECTURAL PURPOSE & DESIGN RATIONALE: The Library subsystem is responsible for organizational domain logic in FolioNote:

  1. Tracking, indexing, and cataloging registered library directory bundles (.foliolib) and their child encapsulated notebook packages (.notebook).
  2. Enforcing the core architectural invariant: all notebooks must reside inside a library.
  3. Handling dual-mode library discovery (packaged .foliolib bundles vs unpacked folders identified by library.meta marker files).
  4. Path sanitization, collision-free routing, and cross-volume package migration.
  5. Quarantine and recovery of discarded notebooks in isolated .trash/ directories.
  6. High-fidelity package cloning without unneeded stroke deserialization.
