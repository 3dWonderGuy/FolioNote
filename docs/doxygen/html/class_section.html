std::string icon = FOLIO_SECTION_DEFAULT_ICON )
inlineexplicit

Constructs a Section with display title, accent color, parent group GUID, and base icon. Guarantees at least one blank "Untitled page" exists upon construction.

LIFECYCLE & PERSISTENCE INVARIANT:

  • If color is omitted or defaulted, a random accent color is chosen via GetRandomSectionColor().
  • When loaded from persistent SQLite storage (LoadNotebookHierarchy), this value is explicitly overwritten with the saved database record (color_r, color_g, color_b, color_a), guaranteeing user color customization is permanently preserved without subsequent re-rolls.
Parameters
sectionNameDisplay title for the section (defaults to "New Section").
colorUI accent color vector (RGBA, defaults to random preset).
parentGroupGUID of owning SectionGroup, or empty for root sections.
iconBase template icon filename (defaults to orange-section-simple.svg).

bool Section::InsertPage ( size_t index,
std::shared_ptr< CanvasPage > page )
inline

Inserts a CanvasPage at a specific index, maintains contiguous sort orders, marks the page dirty for persistence, and logs the operation.

MATHEMATICAL WORKING PROCESS & SORT ORDER SEQUENCING:

  • Clamps insertion index to [0, pages.size()] to prevent vector iterator out-of-bounds.
  • Re-indexes all subsequent page positions monotonically: \forall i \in [0, N-1], \quad pages[i]->sortOrder = i
  • Sets page->isModified = true ensuring the inserted page is scheduled for SQLite upsert.
Parameters
index0-indexed position where the page should be inserted.
pageShared pointer to the CanvasPage to insert.
Returns
bool True if successfully inserted; false if page was nullptr.

◆ MovePage()

bool Section::MovePage ( size_t fromIdx,
size_t toIdx )
inline

Moves a page from one index to another, keeping activePageIndex accurate and logging movement.

INDEX CALCULATION & ACTIVE SELECTION MATH: When an element is moved from fromIdx to toIdx:

  • If activePageIndex == fromIdx, the active index shifts directly to toIdx.
  • If fromIdx < activePageIndex <= toIdx, preceding elements shift left: activePageIndex--.
  • If toIdx <= activePageIndex < fromIdx, following elements shift right: activePageIndex++.
Parameters
fromIdxSource index in pages vector.
toIdxDestination index in pages vector.
Returns
bool True if indices are valid and movement succeeded; false otherwise.
