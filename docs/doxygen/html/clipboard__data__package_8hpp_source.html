2/**
3 * =========================================================================================
4 * @file core/clipboard/clipboard_data_package.hpp
5 * @brief Multi-Format Envelope for Rich Cross-Application and Native Clipboard Payloads
6 * =========================================================================================
7 *
8 * ARCHITECTURAL ROLE:
9 * -------------------
10 * In modern operating systems (Windows OLE, Linux Wayland/X11, macOS Pasteboard), the clipboard
11 * is not a single string or bitmap. It is a multi-format negotiation tray where an application
12 * publishes multiple simultaneous representations ("flavors") of copied canvas objects.
13 *
14 * Supported Clipboard Representations:
15 * ------------------------------------
16 * 1. Native Binary Blob ("application/x-folionote-ink"):
17 * High-performance, delta-compressed binary representation (.ink) containing complete
18 * vector stroke fidelity, pressure dynamics, text attributes, math parameters, and transforms.
19 * Used by FolioNote itself for lossless internal Paste and cross-window copy/paste.
20 *
21 * 2. Vector SVG XML ("image/svg+xml"):
22 * W3C standard vector XML markup representing scalable vector paths, polylines, colors,
23 * and font layouts. Directly pasted into vector suites (Illustrator, Figma, Inkscape)
24 * and modern Microsoft Office (OneNote, Word, PowerPoint).
25 *
26 * 3. Windows Ink / ISF ("application/x-ms-ink" / Ink Serialized Format):
27 * Microsoft's native digital ink stream. When pasted into Microsoft OneNote or Microsoft
28 * Whiteboard, strokes convert into native, editable OneNote ink strokes with pressure.
29 *
30 * 4. High-Resolution Raster Image ("image/png", "image/bmp", CF_DIBV5):
31 * Premultiplied RGBA raster image rendered with alpha transparency. Consumed by standard
32 * raster applications (Discord, Slack, MS Paint, Photoshop, web messengers, email).
33 *
34 * 5. Unicode Plain Text ("text/plain;charset=utf-8", CF_UNICODETEXT):
35 * Plaintext representation (extracted text from TextBoxes, video URLs, markdown notes,
36 * attachment paths).
37 *
38 * MATHEMATICAL FOUNDATIONS:
39 * -------------------------
40 * Collective Spatial Bounding Box:
41 * Given N objects with individual AABB bounding boxes {B_1, B_2, ..., B_N},
42 * the union bounding box is:
43 * B_total = [ min(B_i.minX), min(B_i.minY), max(B_i.maxX), max(B_i.maxY) ]
44 * Dimensions: W = B_total.maxX - B_total.minX, H = B_total.maxY - B_total.minY
45 * Centroid: C = (B_total.minX + W/2, B_total.minY + H/2)
46 *
47 * DPI Scaling for Raster Preview:
48 * Pixel dimensions for high-resolution PNG fallback:
49 * pixelW = round(W_mm * (targetDPI / 25.4))
50 * pixelH = round(H_mm * (targetDPI / 25.4))
51 * Blend2D renders the objects with translation (-B_total.minX, -B_total.minY)
52 * and uniform scale (targetDPI / 25.4).
53 */

96 /**
97 * @brief Checks if the package contains any valid data representations.

103 svgXml.empty() &&
104 pngBytes.empty() &&
