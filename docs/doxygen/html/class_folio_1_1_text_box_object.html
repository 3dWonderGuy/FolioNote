◆ HitTest()

bool Folio::TextBoxObject::HitTest ( double wx,
double wy ) const
overridevirtual

Evaluates whether a world-space point intersects the text box or its top grab bar.

Working Process:

  1. Check visibility & selectability: Rejects hidden or non-selectable text boxes.
  2. Expand bounding box vertically by 4.0mm at the top (hitBox.minY -= 4.0) to account for the interactive text drag handle / grab bar.
  3. Containment test: If (wx, wy) falls inside the expanded hitBox:
    • If already selected (isSelected == true), returns true immediately to support frictionless double-click text editing and drag operations.
    • Otherwise returns true as an interior hit.
Parameters
wxWorld X coordinate in mm.
wyWorld Y coordinate in mm.
Returns
True if (wx, wy) hits the text box or grab handle.
