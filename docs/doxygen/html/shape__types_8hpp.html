Detailed Description

Enum definitions for 2D geometric vector shape categorization.

Separated from shape_container.hpp so that any subsystem (ribbon, engine, serializer, input state machine) can reference shape type constants without pulling in the full ShapeObject class or its Blend2D / ImGui dependencies.

Scalability note: To add a new closed 2D shape primitive, add an entry here and implement the corresponding case in shape_container.cpp::BuildPath(). No other files need modification.
