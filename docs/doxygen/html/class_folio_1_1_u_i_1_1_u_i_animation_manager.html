float Folio::UI::UIAnimationManager::GetFloat ( const std::string & key,
float target,
float speed = 14.0f )

Computes or retrieves a smooth frame-rate independent exponential decay value.

MATHEMATICAL PROCESS: Evaluates $x_{t+\Delta t} = x_{\text{target}} + (x_t - x_{\text{target}}) \cdot e^{-\lambda \Delta t}$. Unlike naive linear interpolation ($x + (T - x) \cdot \alpha$), exponential decay produces strictly identical motion regardless of frame rate (60 FPS vs 120 FPS vs 240 FPS).

Parameters
keyUnique identifier for this animated property.
targetTarget destination value.
speedDecay rate coefficient $\lambda$ (e.g. 12.0f for snappy, 6.0f for gentle).
Returns
Current interpolated value for the active frame.

Evaluates normalized interaction state alphas for an individual ImGui widget.

Smoothly transitions hoverAlpha and activeAlpha across frames:

  • Hover fades in at ~14.0/s, fades out at ~10.0/s.
  • Active (press) snaps in at ~28.0/s, releases smoothly at ~16.0/s.
Parameters
idUnique ImGui widget ID.
isHoveredTrue if cursor currently hovers over widget bounds.
isActiveTrue if widget is currently pressed/held by mouse or stylus.
outHoverAlphaOutput normalized hover transition in [0.0, 1.0].
outActiveAlphaOutput normalized press transition in [0.0, 1.0].

Computes or retrieves a physically simulated damped spring position.

MATHEMATICAL PROCESS: Integrates Newton's second law for a damped harmonic oscillator: $a = -\frac{k}{m} (x - x_{\text{target}}) - \frac{c}{m} v$ $v_{t+\Delta t} = v_t + a \Delta t$ $x_{t+\Delta t} = x_t + v_{t+\Delta t} \Delta t$

Parameters
keyUnique identifier for this spring.
targetEquilibrium target position.
stiffnessSpring stiffness constant $k$ (default 260.0f).
dampingDamping coefficient $c$ (default 24.0f).
Returns
Current spring displacement.
