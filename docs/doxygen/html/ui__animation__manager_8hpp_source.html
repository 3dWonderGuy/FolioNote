2/**
3 * =========================================================================================
4 * @file ui/framework/ui_animation_manager.hpp
5 * @brief Dynamic Transition & Physics-Based Animation Engine for FolioNote UI
6 * =========================================================================================
7 *
8 * GENERAL ARCHITECTURE & WORKING PROCESS:
9 * ---------------------------------------
10 * Modern graphical user interfaces require fluid, responsive transitions to communicate
11 * causality, depth, and spatial hierarchy. Raw ImGui evaluates immediately every frame,
12 * which ordinarily produces abrupt snaps when elements change size, hover, or collapse.
13 *
14 * UIAnimationManager solves this by maintaining a frame-rate independent cache of active
15 * tweens and spring oscillators:
16 * 1. Interaction Alpha Tracking:
17 * Tracks continuous normalized values $t \in [0.0, 1.0]$ for widgets (buttons, tabs, inputs)
18 * during hover, press, and release states.
19 * 2. Continuous Spring Simulation:
20 * Simulates a damped harmonic oscillator ($F = -k(x - x_0) - c v$) for elastic, tactile
21 * feel on button clicks, drawer snapping, and tab sliding badges.
22 * 3. Exponential Decay & Cubic Easing:
23 * Uses frame-rate independent exponential decay ($x_{t+\Delta t} = x_{\text{target}} + (x_t - x_{\text{target}}) e^{-\lambda \Delta t}$)
24 * and Cubic Bezier easing for sliding panels, width expansions, and backdrop fades.
25 */

94 /**
95 * @brief Computes or retrieves a smooth frame-rate independent exponential decay value.
96 *
97 * MATHEMATICAL PROCESS:
98 * Evaluates $x_{t+\Delta t} = x_{\text{target}} + (x_t - x_{\text{target}}) \cdot e^{-\lambda \Delta t}$.
99 * Unlike naive linear interpolation ($x + (T - x) \cdot \alpha$), exponential decay
100 * produces strictly identical motion regardless of frame rate (60 FPS vs 120 FPS vs 240 FPS).
101 *
102 * @param key Unique identifier for this animated property.
103 * @param target Target destination value.
104 * @param speed Decay rate coefficient $\lambda$ (e.g. 12.0f for snappy, 6.0f for gentle).
105 * @return Current interpolated value for the active frame.
106 */
107 float GetFloat(const std::string& key, float target, float speed = 14.0f);
108
109 /**
110 * @brief Computes or retrieves a physically simulated damped spring position.
111 *
112 * MATHEMATICAL PROCESS:
113 * Integrates Newton's second law for a damped harmonic oscillator:
114 * $a = -\frac{k}{m} (x - x_{\text{target}}) - \frac{c}{m} v$
115 * $v_{t+\Delta t} = v_t + a \Delta t$
116 * $x_{t+\Delta t} = x_t + v_{t+\Delta t} \Delta t$
117 *
118 * @param key Unique identifier for this spring.
119 * @param target Equilibrium target position.
120 * @param stiffness Spring stiffness constant $k$ (default 260.0f).
121 * @param damping Damping coefficient $c$ (default 24.0f).
122 * @return Current spring displacement.
123 */
124 float GetSpring(const std::string& key, float target, float stiffness = 260.0f, float damping = 24.0f);
125
126 /**
127 * @brief Evaluates normalized interaction state alphas for an individual ImGui widget.
128 *
129 * Smoothly transitions hoverAlpha and activeAlpha across frames:
130 * - Hover fades in at ~14.0/s, fades out at ~10.0/s.
131 * - Active (press) snaps in at ~28.0/s, releases smoothly at ~16.0/s.
132 *
133 * @param id Unique ImGui widget ID.
134 * @param isHovered True if cursor currently hovers over widget bounds.
135 * @param isActive True if widget is currently pressed/held by mouse or stylus.
136 * @param outHoverAlpha Output normalized hover transition in [0.0, 1.0].
137 * @param outActiveAlpha Output normalized press transition in [0.0, 1.0].
138 */
139 void GetInteractionAlphas(ImGuiID id, bool isHovered, bool isActive, float& outHoverAlpha, float& outActiveAlpha);
