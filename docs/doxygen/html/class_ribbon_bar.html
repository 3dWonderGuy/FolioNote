◆ GetShapeTypeName()

static const char * RibbonBar::GetShapeTypeName ( Folio::ShapeType type)
inlinestatic

Renders the compact 4-column vector shape selection grid palette.

Visual and Layout Organization:

  • Section "Lines": Linear connectors (Line, Line Arrow) with custom 2-point endpoint drag handles.
  • Section "Basic Shapes": 4-column grid of 2D geometric vector primitives: Row 1: Rectangle, Rounded Rectangle, Circle (center-outward), Ellipse (2-step major/minor axis) Row 2: Triangle (Isosceles), Right Triangle (90 deg), Regular Polygon (3-32 sides), Star (5-point)
  • Interactive cells: 42x42 square buttons with embedded anti-aliased Blend2D/ImGui vector icons, hover elevation highlights, active selection indicators, and descriptive tooltips.

Working Process:

  • Creation Mode (Insert / Draw tabs): Selecting a shape synchronizes active pen color, initializes shape type defaults, and transitions input state machine to InteractionState::DrawingShape.
  • Switcher Mode (Shape Format tab): Selecting converts an existing selected shape's geometry, recalculating boundary segments and re-baking the static canvas layer without raster distortion.
Parameters
canvasReference to CanvasEngine.
inputSMReference to InputStateMachine for updating device interaction mode.
themeThemeManager reference for colors and styling.
selectedShapeCurrently selected shape object (if in Shape Format switcher mode).
isSwitcherIf true, switching changes existing selected shape geometry; if false, enters shape drawing mode.

Helper to get the short display name for a given ShapeType.

void RibbonBar::SyncShapePenColor ( CanvasEngine & canvas)
inline

Synchronizes canvas shape default outline color with the currently active inking pen preset.

By default, newly created vector shapes automatically inherit the outline color and opacity of the last used/active inking pen tool while keeping infill transparent (ShapeFillType::None), providing seamless continuity between freehand inking and geometric diagramming.

Parameters
canvasReference to CanvasEngine whose shapeCreation defaults will be updated.
