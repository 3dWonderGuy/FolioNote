2/**
3 * =========================================================================================
4 * @file document_observer.hpp
5 * @brief Event notification listener interface for DocumentSession state changes
6 * =========================================================================================
7 *
8 * ARCHITECTURAL DESIGN & OBSERVER PATTERN:
9 * Follows the classic Gang of Four (GoF) Observer Pattern.
10 * Decouples DocumentSession mutations (page navigation, creation, deletion, dirty flag,
11 * undo/redo changes) from presentation and rendering components (RibbonBar, Sidebar,
12 * CanvasEngine, StatusHUD).
13 *
14 * All virtual methods provide empty default implementations so concrete listeners only
15 * implement the events they care about.
16 */
