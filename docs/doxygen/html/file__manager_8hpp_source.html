2/**
3 * =========================================================================================
4 * @file io/facade/file_manager.hpp
5 * @brief Centralized, Modular, Cross-Platform Filesystem Abstraction Layer for FolioNote
6 * =========================================================================================
7 *
8 * ARCHITECTURAL ROLE & FACADE PATTERN:
9 * FileManager serves as the unified master coordinator for all filesystem and I/O
10 * operations in FolioNote. To maintain clean modularity and keep implementation files
11 * maintainable (< 300 lines each), low-level domains are partitioned into dedicated submodules:
12 *
13 * - PathUtils (io/paths/path_utils.hpp): Unicode-aware path manipulation, normalization, and sanitization.
14 * - AppDirectories (io/paths/app_directories.hpp): Standard application and package folder resolution.
15 * - SystemDialogs (io/platform/system_dialogs.hpp): Native OS file pickers, shell launchers, and clipboard bridge.
16 * - FileWriter (io/storage/file_writer.hpp): Crash-resilient atomic persistence and physical drive synchronization.
17 * - FileReader (io/storage/file_reader.hpp): Cross-platform asset loading, stream acquisition, and content hashing.
18 *
19 * All public interfaces remain accessible via FileManager to guarantee clean,
20 * centralized access across the codebase.
21 */
