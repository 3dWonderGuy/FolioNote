2/**
3 * =========================================================================================
4 * @file page_version_manager.hpp
5 * @brief Google Docs-Style Page Revision History & Disaster Rollback Engine
6 * =========================================================================================
7 *
8 * ARCHITECTURAL ROLE:
9 * PageVersionManager provides point-in-time version control for individual CanvasPages:
10 * 1. Automatic Session Checkpoints: Captures snapshot when interacting with a page during a session.
11 * 2. Named Milestone Versions: Users can pin milestones (e.g., "Draft 1", "Pre-Exam Review").
12 * Named versions are permanent and immune to automatic pruning.
13 * 3. Rolling Retention Pruning: Unnamed session snapshots are automatically capped to N
14 * (configurable in SettingsManager, e.g. 15, or 0 for unlimited).
15 * 4. Non-Destructive Rollback: Reverting to an earlier version automatically creates a safety
16 * snapshot of the active page first so uncommitted work is never lost.
17 * 5. Isolated Storage: Revisions reside in `<notebook>/revisions/<pageGuid>/<versionId>.ink`
18 * with accompanying `<versionId>.meta` telemetry, preserving notebook portability.
19 */
