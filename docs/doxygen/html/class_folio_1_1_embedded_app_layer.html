Updates simulation ticks and renders all mounted apps matching active visible objects.

Updates and renders all mounted apps matching visible canvas objects.

WORKING PROCESS & MATHEMATICAL PROJECTION:

  • Iterates through mounted apps.
  • Resolves the associated CanvasObject from activeObjects.
  • Projects the object's world millimeter bounds (worldX, worldY, worldWidth, worldHeight) through viewport.worldToScreenMatrix into device pixel rectangle AppScreenRegion.
  • Invokes app->Tick(deltaTime) followed by app->RenderApp(region).
Parameters
[in]viewportCurrent camera viewport containing projection matrices.
[in]activeObjectsMap of candidate active CanvasObjects on the current page.
[in]deltaTimeElapsed frame time in seconds.

MATHEMATICAL PROJECTION: Let M = viewport.worldToScreenMatrix: topLeftScreen = M * (worldX, worldY) bottomRightScreen = M * (worldX + worldWidth, worldY + worldHeight) region.x = topLeftScreen.x region.y = topLeftScreen.y region.width = bottomRightScreen.x - topLeftScreen.x region.height = bottomRightScreen.y - topLeftScreen.y

Parameters
[in]viewportCurrent camera viewport with transformation matrices.
[in]activeObjectsActive candidate objects on the current page.
[in]deltaTimeElapsed frame time in seconds.
