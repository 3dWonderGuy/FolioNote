Detailed Description

Implementation of ShapeObject — closed 2D geometric vector shape.

All heavy Blend2D rendering, path construction, hatch pattern generation, hit-testing, and bounds calculation lives here. DrawShapeIconImGui is the sole function that stays in shape_container.hpp because it has an ImGui draw-list dependency that must not enter non-UI translation units.

Organization:

  1. Constructors
  2. BuildPath — geometric path per ShapeType
  3. UpdateBounds — AABB from world coords + transform
  4. HitTest — point-in-shape and proximity tests
  5. BakeTransform — commits accumulated matrix to intrinsic coords
  6. Render — two-pass BLContext draw (infill, outline)
  7. CreateHatchPattern — tiled drafting texture factory
  8. DrawArrowHead — directional arrowhead geometry
  9. DistSqPointToSegment — geometry helper

DrawShapeIconImGui — ImGui icon renderer (header-only, defined here via explicit instantiation to keep it in one place)
