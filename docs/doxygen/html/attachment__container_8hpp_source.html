2/**
3 * =========================================================================================
4 * @file core/objects/attachment_container/attachment_container.hpp
5 * @brief Canvas object representing a file attachment chip pinned to the canvas.
6 * =========================================================================================
7 *
8 * ARCHITECTURAL DESIGN & INVARIANTS:
9 * ----------------------------------
10 * AttachmentObject is a lightweight, non-resizable interactive chip providing
11 * quick access to an external or embedded file (documents, spreadsheets, images, etc.).
12 *
13 * 1. Attachment Modes:
14 * - Link mode (isEmbedded == false):
15 * `filePath` stores the original absolute path on disk. The file is NOT copied.
16 * The chip renders a link badge. If the file is moved/deleted, the link breaks.
17 * - Embedded mode (isEmbedded == true):
18 * The file was copied into the notebook sidecar package folder at attach time.
19 * `filePath` stores the sidecar-relative path. Portable across notebook moves.
20 *
21 * 2. Invariant Geometry & Interaction:
22 * - Fixed-size badge (chipW x chipH mm) with body-move only via GizmoStyle::MoveOnly.
23 * - Double-click dispatches to injected `CanvasContext::fileManager` (zero downcasting).
24 * - Zero direct includes of typography or filesystem managers in this header.
25 */
26
