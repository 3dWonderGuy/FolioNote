2/**
3 * =========================================================================================
4 * @file backup_manager.hpp
5 * @brief Autonomous 3-Tier Multi-Ring Backup & Disaster Recovery Engine
6 * =========================================================================================
7 *
8 * ARCHITECTURAL ROLE:
9 * BackupManager is the dedicated subsystem responsible for offline snapshots, archival,
10 * and disaster recovery of FolioNote data:
11 * 1. 3-Tier Grandfather-Father-Son Retention:
12 * - Tier 1 (Daily / Post-Session): 24h interval, rolling N (default: 7 copies).
13 * - Tier 2 (Weekly): 7d interval, rolling N (default: 4 copies).
14 * - Tier 3 (Monthly): 30d interval, rolling N (default: 12 copies).
15 * - Manual: User on-demand snapshots.
16 * 2. Deep Filesystem Isolation:
17 * Snapshots are organized deep in `<AppRoot>/backups/tiers/{daily,weekly,monthly}/`.
18 * 3. Safe SQLite WAL Checkpointing:
19 * Flushes and truncates SQLite WAL journals (`PRAGMA wal_checkpoint(TRUNCATE)`) prior
20 * to disk copying to eliminate Windows file sharing violations.
21 * 4. Non-Blocking ThreadPool Execution:
22 * All file tree duplications are dispatched to background worker threads.
23 */
24

37enum class BackupTier {
