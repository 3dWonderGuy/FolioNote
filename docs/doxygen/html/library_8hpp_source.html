8 * ARCHITECTURAL PURPOSE & DESIGN RATIONALE:
9 * The Library subsystem is responsible for organizational domain logic in FolioNote:
10 * 1. Tracking, indexing, and cataloging registered library directory bundles (.foliolib)
11 * and their child encapsulated notebook packages (.notebook).
12 * 2. Enforcing the core architectural invariant: all notebooks must reside inside a library.
13 * 3. Handling dual-mode library discovery (packaged .foliolib bundles vs unpacked folders
14 * identified by `library.meta` marker files).
15 * 4. Path sanitization, collision-free routing, and cross-volume package migration.

72 * @brief Package initialization and high-fidelity binary ink replicator.

75 * ARCHITECTURAL ROLE:
76 * Encapsulates low-level database operations (`PageRepository`) and direct binary vector file
77 * cloning away from `LibraryManager`.

79class NotebookCloner {
80public:
81 /**
82 * @brief Synchronously initializes a physical .notebook package directory and its SQLite schema.
83 *
84 * PROCESS:
85 * 1. Creates `<notebook->filePath>/` and `<notebook->filePath>/pages/` subdirectories.
86 * 2. Initializes the SQLite database schema (`pages.db`) using `PageRepository`.
87 * 3. Persists initial notebook metadata and section hierarchy.
88 *
89 * @param notebook Shared pointer to the in-memory Notebook model.
90 * @return true if the package was successfully initialized on disk; false otherwise.
91 */
92 static bool InitializePackage(const std::shared_ptr<Notebook>& notebook);
93
94 /**
95 * @brief Duplicates an existing notebook package with 100% vector fidelity ("Save As Copy").
96 *
97 * PREVENTING LAZY-LOAD STROKE WIPING:
98 * Unrendered pages in memory contain empty stroke collections. Saving via memory serialization
99 * would overwrite on-disk vector data. NotebookCloner clones section hierarchy and metadata,
100 * initializes SQLite structure, and directly copies all raw `.ink` files byte-for-byte from
101 * `<srcPkg>/pages/` to `<dstPkg>/pages/`.
102 *
103 * @param sourceNb Shared pointer to the source notebook being duplicated.
104 * @param newName Proposed title for the duplicate notebook.
105 * @param targetLibraryPath Destination library directory (falls back to fallbackLibraryPath).
106 * @param fallbackLibraryPath Default library fallback if target is empty or invalid.
107 * @return Shared pointer to newly cloned Notebook object, or nullptr on failure.
108 */
109 static std::shared_ptr<Notebook> CloneNotebook(
110 const std::shared_ptr<Notebook>& sourceNb,
111 const std::string& newName,
112 const std::string& targetLibraryPath,
113 const std::string& fallbackLibraryPath
114 );
115
116 /**
117 * @brief Directly copies raw `.ink` binary vector files between package `pages/` directories.
118 *
119 * @param srcPackagePath Absolute filesystem path to source .notebook package directory.
120 * @param dstPackagePath Absolute filesystem path to destination .notebook package directory.
121 * @return Count of `.ink` page stroke files copied.
122 */
123 static size_t CopyPageInkFiles(
124 const std::string& srcPackagePath,
125 const std::string& dstPackagePath
126 );
127};
