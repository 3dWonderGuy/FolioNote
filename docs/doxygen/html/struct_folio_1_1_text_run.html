Detailed Description

One contiguous styled text span or inline element in a rich text document.

Multiple TextRun objects are stored in sequence inside TextBoxObject::runs. The visual result is produced by iterating runs in order and laying out each span with its specified style or inline element dimensions.

Example (bold "Hello" followed by plain " world"): runs[0] = { text="Hello", bold=true, fontSize=16 } runs[1] = { text=" world", bold=false, fontSize=16 }

◆ linkRef

std::string Folio::TextRun::linkRef = ""

UUID of a canvas LinkObject this run links to.

If empty: plain text, no hyperlink behavior. If non-empty: text renderer draws this run in accent color + underline, and a click triggers LinkObject::Navigate() on the referenced object.

The LinkObject lives in the canvas object list (same Section/Page). Its guuid must match this string exactly.
