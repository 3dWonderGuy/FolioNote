2/**
3 * @file text_editor_state.hpp
4 * @brief Slint-proof, headless text editor controller and caret engine.
5 *
6 * Implements an interactive text editing controller decoupled from any UI toolkit.
7 * Receives raw character input and keycodes forwarded from the windowing layer
8 * (SDL3, Slint, or Qt) and drives the text document model (TextBoxObject).
9 *
10 * Mathematical & Typographical Model:
11 * -----------------------------------
12 * - Lines are computed with explicit line breaks ('\n') and word wrapping within worldWidth.
13 * - Cursor position is represented as a character index [0, totalChars].
14 * - Caret world coordinates (worldX, worldY) are computed using Blend2D font metrics
15 * (ascent, descent, advance) provided by FontManager.
16 * - Selection range is defined by [min(anchor, cursor), max(anchor, cursor)].
17 */
