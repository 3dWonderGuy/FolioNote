2/**
3 * @file text_run.hpp
4 * @brief A single styled text span within a TextBoxObject's rich content model.
5 *
6 * TextRun is the atomic unit of rich text in FolioNote. A TextBoxObject stores
7 * a vector<TextRun> where each element defines one contiguous styled region.
8 * Adjacent runs with identical styling should be merged for efficiency.
9 *
10 * Phase 2 Rich Text Implementation Plan:
11 * ─────────────────────────────────────────────────────────────────────────────
12 * The rich text system operates on two layers:
13 *
14 * LIVE LAYER (while isEditing == true):
15 * Re-rendered every frame at current zoom. Uses Blend2D BLFont with the
16 * platform font stack (fontFamily matched against system fonts via
17 * FreeType / DirectWrite / CoreText). Zoom-aware: fontSize * canvasZoom
18 * gives screen pixel size so text appears at its intended physical size.
19 *
20 * BAKED LAYER (while isEditing == false):
21 * A BLImage snapshot rendered at the zoom level at time of baking (or at
22 * a fixed reference DPI). The engine draws the cached BLImage as a bitmap
23 * (fast, no font loading). On next selection+edit, the live layer resumes.
24 * The baked image is a selectable, moveable object — functionally identical
25 * to ImageObject once baked.
26 *
27 * Inline Link Reference:
28 * linkRef stores the UUID of a canvas LinkObject. The text editor draws
29 * runs with a non-empty linkRef in accent color with underline, and a single
30 * click in Phase 2 will call LinkObject::Navigate().
31 * ─────────────────────────────────────────────────────────────────────────────
32 *
33 * Scalability:
34 * Add new style attributes (superscript, subscript, custom baseline offset,
35 * font stretch, language code for hyphenation) by extending this struct.
36 * The text layout engine reads all fields — no other files need modification.
37 */
