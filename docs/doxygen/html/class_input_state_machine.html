float currentY,

Computes velocity-scaled dynamic eraser radius when isDynamicEraser is active. Faster movement expands the swept radius for broad wiping; slower movement contracts for surgical precision.

Computes velocity-scaled dynamic eraser radius when isDynamicEraser is active.

Mathematical Model: Let dt = currentTimeSec - lastEraserTimeSec. Pointer displacement distPx = hypot(dx, dy). Instantaneous velocity v = distPx / dt in pixels per second.

Normalized velocity parameter t = clamp((v - 100.0) / 1900.0, 0.0, 1.0). Response curve: s = sqrt(t) (concave curve providing fast initial scaling). Target radius: R_target = R_min + s * (R_max - R_min).

Asymmetric smoothing: alpha = 0.35 when expanding (fast swipe opens broad wiping swath). alpha = 0.12 when contracting (gentle recovery prevents jitter). R_current += alpha * (R_target - R_current).

◆ UpdateHardwareState()

void InputStateMachine::UpdateHardwareState ( uint64_t nowMs)
private

Resolves active input device and handles tool memory restoration & transient overrides.

ARBITRATION MATHEMATICAL FORMULATION:

Let $t$ be the current timestamp nowMs. Let $t_{pen}$ be lastPenTimestampMs and $t_{touch}$ be lastTouchTimestampMs.

Condition for Stylus Priority: $C_{stylus} = \text{pen.isDown} \lor \text{pen.inProximity} \lor \text{pen.isHovering} \lor (t - t_{pen} < T_{pen_grace})$

Condition for Touch Priority (if Stylus inactive): $C_{touch} = (\text{fingerCount} > 0) \lor (t - t_{touch} < T_{touch_grace})$

Otherwise: Fallback to Mouse.

Parameters
nowMsSystem tick in milliseconds from SDL_GetTicks().
