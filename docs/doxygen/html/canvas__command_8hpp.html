Detailed Description

Command interfaces and concrete action records for the Undo/Redo subsystem.

autotoc_md165

ARCHITECTURAL DESIGN: Follows the Command Pattern to encapsulate canvas mutations into discrete, reversible units. Supports:

  1. Single Object Insertion: Pen strokes, images, text boxes, shapes.
  2. Multi-Object Deletion: Delete key, cut, selection removal.
  3. Compound Continuous Eraser Actions: Groups multiple erased strokes and sliced fragments from a single continuous pen gesture into one single undoable action.
  4. Multi-Object Transformation: Gizmo moving, scaling, and rotating.
