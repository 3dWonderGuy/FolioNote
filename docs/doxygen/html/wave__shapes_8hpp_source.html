2/**
3 * @file wave_shapes.hpp
4 * @brief Algorithmic path generation and mathematical modeling for wave shapes (Sine Wave, Square Wave).
5 *
6 * Mathematical Foundations:
7 * -------------------------
8 * 1. Sine Wave:
9 * A continuous periodic trigonometric waveform defined across the horizontal interval [x, x + W]
10 * with vertical bounding extent [y, y + H]:
11 * y_center = y + H / 2 (equilibrium baseline)
12 * Amplitude A = H / 2 (half of peak-to-peak height)
13 * Spatial Frequency f = N / W (cycles per world unit, where N = cycle count)
14 * Wavelength λ = W / N (horizontal length of one complete period)
15 *
16 * The elevation at any horizontal position x' in [x, x + W] is given by:
17 * y(x') = y_center - A * sin(2π * N * (x' - x) / W)
18 * (Note: In canvas coordinate systems, +y points downwards. The minus sign ensures that the
19 * initial half-cycle ascends towards the top of the canvas, matching standard scientific conventions.)
20 *
21 * 2. Square Wave:
22 * A piecewise-constant alternating pulse waveform with sharp transitions between high and low rails:
23 * y_center = y + H / 2
24 * High rail: y_high = y (top edge, y_center - A)
25 * Low rail: y_low = y + H (bottom edge, y_center + A)
26 * Period T = W / N
27 *
28 * For each cycle k ∈ [0, N):
29 * - Step from baseline y_center to y_high at x_k = x + k * T (or transition from previous cycle)
30 * - Horizontal pulse along y_high for duration T * dutyCycle (default dutyCycle = 0.5)
31 * - Vertical step down from y_high to y_low at x_k + T * dutyCycle
32 * - Horizontal pulse along y_low for duration T * (1 - dutyCycle)
33 * - Vertical step at cycle completion
34 * - Final closure returns to baseline y_center at x + W.
35 *
36 * Transformation & Dynamic Stretch Contract:
37 * ------------------------------------------
38 * - Horizontal stretching (scaling W) scales the period T, modifying the spatial frequency f = N / W.
39 * Live gizmo scale expands or contracts the cycles in real time.
40 * - Vertical stretching (scaling H) scales the amplitude A = H / 2.
41 * - The cycle count N is maintained via param1 (default = 3.0), adjustable via the ribbon UI.
42 */

65 /**
66 * @brief Procedurally builds a smooth Blend2D path for a continuous Sine Wave.
67 *
68 * Mathematical Process:
69 * 1. Clamps width W and height H to minimum thresholds (0.01 mm) to avoid division by zero.
70 * 2. Computes the baseline y_center = y + H * 0.5 and amplitude A = H * 0.5.
71 * 3. Adapts sample resolution dynamically based on cycle count:
72 * samples = max(64, int(cycles * 32.0))
73 * This ensures crisp, curvature-accurate rendering without aliasing even at high frequencies.
74 * 4. Evaluates y(t) = y_center - A * sin(2π * cycles * t) for t ∈ [0, 1].
75 * 5. Appends line segments to the BLPath. Blend2D stroking with round joins creates a C∞-smooth curve.
76 *
77 * @param path Output BLPath (cleared before generation).
78 * @param x Top-left X coordinate of the bounding box (world millimeters).
79 * @param y Top-left Y coordinate of the bounding box (world millimeters).
80 * @param width Horizontal span / length of the wave (world millimeters).
81 * @param height Total vertical peak-to-peak extent (world millimeters).
82 * @param cycles Total number of complete sine periods across the width (param1).
83 */
84 static void BuildSineWavePath(BLPath& path,
85 double x, double y,
86 double width, double height,
87 double cycles);

89 /**
90 * @brief Procedurally builds a Blend2D path for an orthogonal Square Wave.
91 *
92 * Mathematical Process:
93 * 1. Determines high rail (y_high = y), low rail (y_low = y + height), and baseline (y_center = y + height * 0.5).
94 * 2. Partitions the horizontal span into N cycles of period T = width / cycles.
95 * 3. Starts path at (x, y_center).
96 * 4. For each cycle k from 0 up to floor(cycles):
97 * - Climbs vertically to (x_k, y_high).
98 * - Traces high plateau to (x_k + T * dutyCycle, y_high).
99 * - Drops vertically to (x_k + T * dutyCycle, y_low).
100 * - Traces low plateau to (x_{k+1}, y_low).
101 * 5. Accommodates fractional remaining cycles if cycles is non-integer.
102 * 6. Concludes with a vertical return to the baseline (x + width, y_center).
103 *
104 * @param path Output BLPath (cleared before generation).
105 * @param x Top-left X coordinate of the bounding box (world millimeters).
106 * @param y Top-left Y coordinate of the bounding box (world millimeters).
107 * @param width Horizontal span / length of the wave (world millimeters).
108 * @param height Total vertical peak-to-peak extent (world millimeters).
109 * @param cycles Total number of periods across the width (param1).
110 * @param dutyCycle Ratio of high-rail duration to full period (default = 0.5, symmetric).
111 */
112 static void BuildSquareWavePath(BLPath& path,
113 double x, double y,
114 double width, double height,
115 double cycles,
116 double dutyCycle = 0.5);

146 /**
147 * @brief Procedurally builds a Blend2D path for a symmetric Triangle Wave.
148 *
149 * Mathematical Process:
150 * 1. Baseline y_center = y + height * 0.5, amplitude A = height * 0.5.
151 * 2. Period T = width / cycles.
152 * 3. For each cycle k from 0 to ceil(cycles):
153 * - Start at baseline: (x_k, y_center)
154 * - Ascend linearly to peak: (x_k + 0.25 * T, y)
155 * - Descend linearly through baseline to trough: (x_k + 0.75 * T, y + height)
156 * - Ascend linearly back to baseline: (x_k + T, y_center)
157 * 4. Clamps x coordinates to [x, x + width] and concludes at (x + width, y_center).
158 *
159 * @param path Output BLPath (cleared before generation).
160 * @param x Top-left X coordinate of the bounding box (world millimeters).
161 * @param y Top-left Y coordinate of the bounding box (world millimeters).
162 * @param width Horizontal span / length of the wave (world millimeters).
163 * @param height Total vertical peak-to-peak extent (world millimeters).

171 /**
172 * @brief Procedurally builds a Blend2D path for a Right Triangle (Sawtooth / Ramp) Wave.
173 *
174 * Mathematical Process:
175 * 1. Baseline y_center = y + height * 0.5, peak y_top = y, trough y_bottom = y + height.
176 * 2. Period T = width / cycles.
177 * 3. If rightAngleOnRight is true (default, Ramp Up):
178 * - In each cycle: linear ramp ascending from (x_k, y_bottom) to (x_k + T, y_top).
179 * - Vertical drop at x_k + T from (x_k + T, y_top) to (x_k + T, y_bottom), forming a right angle on the right.
180 * 4. If rightAngleOnRight is false (Ramp Down):
181 * - In each cycle: vertical rise at x_k from (x_k, y_bottom) to (x_k, y_top), forming a right angle on the left.
182 * - Linear ramp descending from (x_k, y_top) to (x_k + T, y_bottom).
183 * 5. Start and end points anchor smoothly to baseline (x, y_center) and (x + width, y_center).
184 *
185 * @param path Output BLPath (cleared before generation).
186 * @param x Top-left X coordinate of the bounding box (world millimeters).
187 * @param y Top-left Y coordinate of the bounding box (world millimeters).
188 * @param width Horizontal span / length of the wave (world millimeters).
189 * @param height Total vertical peak-to-peak extent (world millimeters).
190 * @param cycles Total number of periods across the width (param1).
191 * @param rightAngleOnRight True if the vertical edge (right angle) is on the right; false if on the left (param2).
192 */
