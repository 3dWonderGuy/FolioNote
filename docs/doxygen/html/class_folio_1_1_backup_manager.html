void Folio::BackupManager::CheckAndRunScheduledBackups ( const std::string & libraryPath,
const std::string & customRoot = "" )
static

Evaluates elapsed timestamps and runs any due scheduled multi-ring backups (Daily, Weekly, Monthly).

MATHEMATICAL SCHEDULING LOGIC:

  • Evaluates $\Delta t_{\text{daily}} \ge 24\text{h}$, $\Delta t_{\text{weekly}} \ge 7\text{d}$, $\Delta t_{\text{monthly}} \ge 30\text{d}$.
  • Dispatches snapshots and prunes obsolete snapshots per configured tier retention caps.
Parameters
libraryPathRoot path of the active library to back up.
customRootOptional backups storage root (defaults to <AppRoot>/backups).
