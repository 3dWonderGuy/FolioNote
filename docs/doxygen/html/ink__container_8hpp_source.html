2/**
3 * =========================================================================================
4 * @file core/objects/ink_container/ink_container.hpp
5 * @brief High-Performance Baked Vector Ink Container and Stroke Geometry Model
6 * =========================================================================================
7 *
8 * ARCHITECTURAL DESIGN:
9 * ---------------------
10 * `InkContainer` inherits from `CanvasObject` and acts as the persistent entity for freehand
11 * vector inking on the infinite canvas.
12 *
13 * It provides:
14 * 1. Dual-Representation Vector Model:
15 * - Closed 2D polygon ribbon outline (BLPath) for zero-seam, hardware-accelerated
16 * SIMD non-zero fill rendering via Blend2D.
17 * - Discrete spatial centerline points (StrokePoint) and segments (Segment1D) for
18 * precision distance-based hit testing, proximity selection, and point eraser slicing.
19 * 2. Rich Pen Semantics:
20 * - Per-stroke BlendMode (Normal/SrcOver, Multiply for Highlighters, Additive for Glow/Neon).
21 * - Configurable CapType (Round, Flat, Chisel, Square) and StrokePattern (Solid, Dashed, Dotted, DashDot).
22 * 3. Affine Geometry Transformations:
23 * - Real-time interactive transformation via 2D affine matrix (BLMatrix2D).
24 * - Geometric transform baking committing scaling, translation, and rotation directly into
25 * centerline points, segments, and polygon outline hulls.
26 * 4. High-Performance Two-Tier Hit Testing & Eraser Slicing:
27 * - Broadphase AABB query rejection.
28 * - Narrowphase inverted-transform spatial evaluation (exact segment Euclidean distance,
29 * continuous swept-capsule testing, and quadratic circle-segment eraser splitting).
30 */

54/**
55 * @struct Stroke
56 * @brief Vector stroke entity encapsulating canonical centerline geometry and ephemeral render caches.
57 *
58 * DATA STORAGE CONTRACT:
59 * - Database & Serialization: ONLY the Canonical Centerline Vector Model and style attributes
60 * are serialized to disk or SQLite. Polygons and segment trees are NEVER stored permanently.
61 * - Runtime Acceleration: `segments`, `outlinePath`, and `bounds` are transient caches generated
62 * in memory via StrokeOutlineBuilder::GenerateRibbon() and StrokeCollision::BuildSegments()
63 * upon document loading or when points are modified.
64 */

90 /**
91 * @brief Maps internal BlendMode to Blend2D composite operator.
