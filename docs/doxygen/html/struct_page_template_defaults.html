Detailed Description

Default paper styling, encapsulated border configuration, and spatial dimensions for new pages.

Theme-driven colors (such as dark/inverted paper and grid lines) are managed globally via ThemeManager / ObjectConfig. Templates specify structural paper style and encapsulated border metrics.
