Ingests a PDF document into the notebook package, either copying and deduplicating into imports/pdfs/ or linking externally based on mode.

Working Process:

  1. Calls InspectPdf to validate source file and extract content hash.
  2. For ExternalLink mode, stores direct absolute path without copying bytes.
  3. For LocalCopy mode, ensures destination directory <notebookPkg>/imports/pdfs exists.
  4. Copies the source file into imports/pdfs/pdf_<contentHash>.pdf via FileManager::CopyFileTo. (Named CopyFileTo rather than CopyFile to avoid the Win32 CopyFileA macro collision.)
Parameters
srcPathUTF-8 path to the source PDF file.
sessionActive document session providing notebook workspace root.
modeLocal copy vs external link mode.
outInfoDestination struct receiving paths and metadata.
Returns
true if successfully ingested, false otherwise.

static bool Folio::PdfStorage::InspectPdf ( const std::string & srcPath,
PdfDocumentInfo & outInfo )
inlinestatic

Inspects an external PDF file without modifying it, returning metadata, detected page count, and recommendation flags.

Working Process:

  1. Validates that the input source file exists via FileManager::Exists.
  2. Computes a 64-bit FNV-1a content hash for package deduplication.
  3. Uses PdfRenderer::GetPageCount (PDFium) to accurately parse the document catalog, page tree B-tree, compressed object streams (/ObjStm), and cross-reference streams.
  4. If PDFium is unavailable or fails, gracefully falls back to FileLoader::DetectPdfPageCount.
  5. Flags documents with >= 20 pages as long documents and populates recommendation warnings.
Parameters
srcPathUTF-8 path to the PDF on disk.
outInfoDestination struct for populated metadata and page count.
Returns
true on successful inspection, false if file does not exist or cannot be read.
