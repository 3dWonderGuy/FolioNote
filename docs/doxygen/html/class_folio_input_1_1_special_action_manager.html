Evaluates a click/tap event to determine if it completes a double-click gesture.

MATHEMATICAL LOGIC:

Let previous tap be at $(x_1, y_1)$ at time $t_1$. Let incoming tap be at $(x_2, y_2)$ at time $t_2$.

The incoming tap is classified as a Double-Click if and only if:

  1. Temporal constraint: $\Delta t = t_2 - t_1 \le T_{\text{max}} \quad (\text{default } 300\,\text{ms})$
  2. Spatial constraint: $D = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2} \le R_{\text{max}} \quad (\text{default } 12\,\text{px})$
Parameters
xPixel X position of the click in window coordinates.
yPixel Y position of the click in window coordinates.
nowMsCurrent system timestamp in milliseconds.
configConfiguration parameters supplying temporal and spatial thresholds.
Returns
true if a double-click was recognized, false otherwise.
